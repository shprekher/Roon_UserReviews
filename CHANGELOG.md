# Changelog

## 0.1.0 — 2026-10-26

- Source-only release of the folder-aware native review bridge.
- Zero per-album registration and no project database writes.
- Live UTF-8 file reading; multi-disc discovery, ambiguity handling, online-first
  ordering, explicit local selection, and **User review.** source label.
- Exact-build offline patcher, local stopped-Core DLL tool, rollback instructions,
  synthetic tests, private integration-test harness, pinned CI, and source-only
  packaging/content guards.
- Removed private installation material and obsolete database/research/protocol
  tooling from the public distribution, without deleting the working installation.

Experimental source-only release, authorized by the owner after two audits.
Compilation is required; a downloadable installer is a separate future stage.
No proprietary Roon binaries are distributed. Checksums and tags are unsigned.
See docs/RELEASE-CHECKLIST.md for remaining validation and owner-review items;
publication does not certify those items as completed.
